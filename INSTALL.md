# pg_analyse installation

Python `pip` package is required to install `pg_analyse`.

## From sources

Use the following command line to install `pg_analyse` from sources directory (containing `pyproject.toml`):

```shell
pip install .
```

## From PyPI

Alternatively you can install `pg_analyse` from PyPI:

```shell
pip install pg_analyse
```

To install it with command line interface support:

```shell
pip install pg_analyse[cli]
```

Use `-U` flag for upgrade:

```shell
pip install -U pg_analyse
```
